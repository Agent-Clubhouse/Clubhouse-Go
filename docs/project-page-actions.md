# Project page (#442)

The page has one New agent / Terminal row, a shared desktop-chip scope for linked members, Needs you followed by Agents, and a single sleeping/retained-finished disclosure. Whole helper subtrees stay together when a helper needs attention, preserving their parent disclosure and collapsed preference. Historical exited agents are omitted from active rows and appear once as retained runs; Dismiss/Clear use the existing desktop commands. Offline members retain a placeholder without presenting their cached agent tree as live.

The toolbar menu offers Wake with a message and the functional read-only Project info sheet from #443. Linked projects use the same authoritative group Pin/Unpin and Active/Inactive menu component as Home, including unavailable/mixed-version guards and the connection hint. Scoping the page to one desktop never narrows the shared group state change. Single projects retain the existing Pin / Inactive policy: desktop shared project state when available, existing local preferences otherwise, pinned projects kept active. Changes is removed from the page, including its automatic read. Domain changes/diff decoding and service tests remain; the obsolete project-page UI path through Changes is intentionally removed from the smoke scenario.

For linked projects, All → Terminal / Wake opens an explicit machine chooser; a selected member acts directly unless multiple project copies share that machine, in which case the chooser disambiguates them. No operation fans out. Availability is checked both in the chooser and again after dismissal, and Wake opens chat only after its sheet finishes dismissing. New agent continues through the existing linked-project spawn chooser.

Old hosts without the linked-state contract keep per-machine submenus using the existing single-project state policy: desktop state where available, local preferences otherwise. A migrated group with unavailable authority stays disabled with its connection hint; it never silently falls back to per-copy changes.
