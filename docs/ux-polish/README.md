# Clubhouse Go UX polish: comps

Assets for the UX polish epic. `today/` are captures of the current build running its own preview data (iPhone 17 Pro, iOS 26). `comps/` are HTML mockups of the proposed SwiftUI changes, rendered at phone size. Glyphs are SF Symbol stand-ins and avatar photos are illustrated placeholders; follow the issue text where they differ.

This branch holds images only and is not meant to be merged.
