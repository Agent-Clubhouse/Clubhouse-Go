of the expected title-containing popover and public dismiss region, guards

existing full conversation viewport call is unchanged, including all keyboard

unchanged `outsidePoint` on dismiss-region intersected with conversation
viewport. If that returns a point, the prior geometry choice is retained.

Only if there is no eligible first point, before any tap, the SAME unique

inset. The final point must be inside the native dismiss region and actual
window and outside the entire popover before exactly one existing cancellation
tap. Missing/duplicate/unhittable/invalid geometry or no safe side fails closed;
there is no second tap, retry, extra wait or threshold relaxation. The original
five-second combined title-and-destructive-action disappearance predicate and
all later draft/image/noIO/refocus/dismiss assertions remain byte-identical.
