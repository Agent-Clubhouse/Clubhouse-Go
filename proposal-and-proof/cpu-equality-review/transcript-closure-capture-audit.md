# #582 transcript equality: complete transitive capture audit

Scope: the three closures supplied by CompanionConversationView.timeline to CompanionConversationTranscript. They capture the parent View value, but the following is the complete set of fields actually accessed by their bodies and called parent helpers. No unused field of the captured self is assumed current. No action closure contains a captured conversation/items snapshot.

| Closure / transitive helper | Values read | Freshness / equality boundary |
| --- | --- | --- |
| `header -> timelineHeader` | `conversation.hasEarlierMessages`, `conversation.items.isEmpty`; `recoveryStatus` | `conversation` calls `store.conversation(for: target)` at invocation. Recovery reads the current Store conversation loading/resync/error and current host connection. Store identity and target are equality keys. |
| Header archive button action | `showArchive = true` | The parent @State wrapper retains the same installed storage for this parent identity. The parent still owns `.sheet(isPresented: $showArchive)`; equality only gates its transcript child. Focused native UI proof taps this real button after streaming and opens/closes the actual archive sheet. |
| `entry -> timelineEntry` | Function parameters `entry`, `items` | Both parameters come from the current child's current rows/conversation; neither is captured in the retained builder. `.slice` delegates to `messageView`; references are derived from that current message. `.row` delegates to `timelineRow`. |
| `timelineRow` message/tool/approval/question/notice | `row`, `items` parameters | Passed to `timelineItem` as current child values. |
| `timelineRow` desktop question group | `group` parameter; current host name | Group is a current row parameter; host name is read from `store.host(for: target)` when invoked. |

| `timelineItem` tool | Current tool, current expansion state, current item links | Store expansion lookup occurs when invoked, keyed by current tool id; references use current item. |

That capability set is an explicit equality key so a new catalog capability replaces the builder. Persistent support calls Store currently. `actionsArePinned = true` is a constant. |

| `messageView` | Current message/slice parameters; Store.canSend; Store.canOperate/pendingCommands; `agent.capabilities`; Store expansion | Store lookups occur at invocation. Only the captured immutable capability set can stale; it is an explicit equality key. No agent.name/status/access/profile/lastActivity or connection snapshot is read here. |
| Message retry action | Current message id, Store, fixed target | Retry resolves through current Store guard when activated. No draft or permission snapshot is captured. |
| Queued-remove action | Current message id, Store, fixed target | Closure presence and enabled flag derive from the capability equality key plus current Store guards; Store.removeQueuedMessage re-checks live safety on activation. |
| `dismissComposer` | `composerDismissals &+= 1`; UIApplication responder operation | Parent @State storage stays installed and shared by the retained closure. UIApplication.shared/sendAction resolves at invocation; no focus/controller/keyboard snapshot is captured. |

`target` is the parent's `agent.id`, compared explicitly. `agent.capabilities` is the ONLY other Agent field read by these builders; it is compared explicitly. `opening` is the seed owner's immutable cached value, compared explicitly. `isVisibilityManaged` and `decisionChatJump?.id` are compared explicitly. A new request id cannot be swallowed; a repeated id does not replay while mounted, preserving the existing once-per-reveal policy.

No parent @Environment value is read by these three closures or their called parent helpers. Recovery reads current Store, not an environment snapshot. The transcript's own reduce-motion/dynamic-type/ScaledMetric and descendant palette/full-event-presenter/sender-resolution environments remain native environment dependencies; Equatable does not suppress their own invalidations. Reading State, Store/viewport Observation and scroll-position invalidation remain inside the child and outside equality.

DEBUG row availability observer: records the SAME shared values passed to the actual ApprovalCard and MessageView constructors. It reads/writes no View State, supplies no action path, and is reset with defer. It is not a native activation claim. The transient diagnostic's attribution callback, _printChanges calls and printed payloads are absent from the product tree and all credited overlays.
