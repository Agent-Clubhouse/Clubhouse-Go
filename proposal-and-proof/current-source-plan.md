## Revision after QA direction review (before code)

Use the simpler transcript-child scope, not the keyed cache. Extract the existing timeline builder and reading-only helpers into a private `CompanionConversationTranscript` View. Its four State values (plus existing reading-only debug/control State) live inside the subtree that is already removed by `isVisible=false`. Parent composer/draft/header State stays in CompanionConversationView. Give the child `.id(target)` so a same-identity parent target change cannot share reading State. A target-keyed outer scope uses StateObject’s lazy autoclosure to calculate one immutable opening seed per actual mount. Discarded View initializers do not execute the bookmark lookup, row scan or candidate slicing. The transcript initializer only copies this value into its existing State. SwiftUI retains both seed and reading State across ordinary parent re-evaluation. Existing onDisappear/managed-visibility geometry authorities remain exactly as today; no cache or manual State reset required.

Pass the existing header and entry builders as ViewBuilder closures and the existing composer-dismiss action, rather than moving the composer or changing row/menu logic. This is a mechanical extraction first; final diff will separate moved code from behavioural edits. The same-target historyRevision task, including window widening and stale-geometry rejection, remains unchanged. No historyRevision key, no reseeding during reload/resync/streaming. Explicit hosted controls cover reload while paused/open and while hidden, with exactly one new seed on re-show.

For a paused bookmark with an entry ID, seed ScrollPosition(id: saved.entryID, anchor:.top), using the SDK's public initializer, with scrollTargetLayout on the existing stack of entries. The latest path retains the bottom-edge seed; the existing missing-entry/old-session fallback stays with the unchanged history task. First-frame evidence must cover a bookmark below the loaded window's first row (earlier messages expanded), proving ID positioning rather than assuming the window starts at the bookmark. Measure the first rendered bookmark's distance and label this row-level semantic paint, not six-point final restoration. Verify alias/grouped-entry IDs before deciding whether a tiny canonical-ID adapter is needed; do not add guessed offsets or alter window bounds just to pass.

Allow Latest from the paused semantic seed until the first nonempty live metrics arrive, then use actual geometry immediately. This provisional control state must neither save a position nor cancel restoration. All post-layout six-point/prefix/cancellation and scrolling assertions remain unchanged. New scrollTargetLayout must be covered by the existing gestures, native top, rotation, streaming and Latest controls, as well as first-frame measurements. The small CompanionReadingSeed owner retains only its immutable Opening value (Bool, Int and optional String), with explicit nonisolated empty deinit and an arc_only policy entry. It retains no Store, target, callback, task or mutable ScrollPosition. The compiled gate and constructor inventory must pass.

Please confirm this revised, narrower product shape before implementation; the original cache design is superseded.
